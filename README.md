## Overview

**Due Two** is a student-founded technology startup focused on developing practical digital solutions and exploring innovative applications across Artificial Intelligence, Computer Vision, Robotics, Embedded Systems, Software Engineering, and Web Development.

This repository contains the source code for the official Due Two website, created to introduce the company, present its services and selected projects, showcase its technology stack, and provide a central point of contact for potential clients and collaborators.

🌐 **Live Website:** [aytenakl.github.io/Due_Two](https://aytenakl.github.io/Due_Two/)

## Features

- **Company Profile** — Introduction to Due Two, its founders, mission, and vision.
- **Services Showcase** — An overview of the company's technology areas and solutions.
- **Project Portfolio** — Selected projects in web development, computer vision, robotics, and embedded systems.
- **Technology Stack** — Technologies used across the team's projects.
- **Why Due Two** — The team's approach to collaboration, problem-solving, and solution development.
- **Contact Information** — Direct links for inquiries and potential collaborations.
- **Responsive Interface** — A modern layout designed for different screen sizes.
- **Interactive Navigation** — Navigation links connecting visitors to the website's main sections.

## Getting Started

To explore or run the website locally:

### 1. Clone the repository

```bash
git clone https://github.com/aytenakl/Due_Two.git
```

### 2. Open the project directory

```bash
cd Due_Two
```

### 3. Run the website

Open `index.html` in your browser.

No build process is required for the basic static website.
