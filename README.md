## 🚀 Featured Projects

### 👁️ AI, Computer Vision & Robotics

**[HandDrive](https://github.com/aytenakl/HandDrive)**

A gesture-controlled robotic car that uses real-time hand tracking to translate human gestures into vehicle movement commands.

*Tech Stack:* Python · OpenCV · MediaPipe · Arduino · L298N

**[Hand-Controlled Robotic Arm](https://github.com/aytenakl/HandControlled-Robotic-Arm)**

A human-robot interaction project that interprets hand gestures and controls a robotic arm with five servo motors.

*Tech Stack:* Python · OpenCV · MediaPipe · Arduino

**[Automated Pick-and-Place Robotic Arm](https://github.com/aytenakl/Automated-Pick-and-Place-Robotic-Arm)**

A robotic system designed to automate object handling through multi-axis motion, motor control, and a servo-driven gripper.

*Tech Stack:* Arduino · C++ · TMC2209 · A4988

**[Real-Time Object Detection using YOLOv8](https://github.com/aytenakl/Real-Time-Object-Detection-using-YOLOv8)**

A computer vision project exploring real-time object detection using the YOLOv8 framework.

*Tech Stack:* Python · YOLOv8 · Computer Vision
