🤖 Automated Pick-and-Place Robotic Arm

An automated robotic system developed by Due Two, combining embedded systems, robotics, motion control, and automation. The project performs continuous pick-and-place operations using multiple stepper motors and a servo-controlled robotic gripper.

Technologies: C++ • Arduino • Stepper Motors • Servo Motor • TMC2209 • A4988 • UART

  • Automated pick-and-place operation
  • Automatic homing for the X and Y axes
  • Stepper motor control for X, Y, and Z axes
  • Servo-controlled robotic gripper
  • TMC2209 stepper motor drivers with UART communication
  • Continuous automated transfer cycles

Status: Completed ✅
